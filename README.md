# Portafolio de Sebastián Escobar

Sitio estático preparado para GitHub Pages. No necesita instalar programas ni ejecutar comandos.

## Cómo publicarlo

1. Crea o abre el repositorio que usarás para tu portafolio.
2. Sube a la raíz del repositorio todos los archivos y la carpeta `assets` contenidos aquí.
3. En GitHub, entra a **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama **main**, la carpeta **/(root)** y presiona **Save**.
6. GitHub mostrará la dirección pública cuando termine la publicación.

## Archivos principales

- `index.html`: contenido del sitio y trabajos.
- `styles.css`: diseño visual y adaptación a celular.
- `script.js`: filtros de Política, Nacional y Mundo.
- `assets/`: currículum, imagen para redes sociales e ícono.

Para actualizar una nota en el futuro, edita el bloque correspondiente en `index.html` o vuelve a generar el sitio desde el proyecto fuente.
